# Agent Engineering Cases

Семь инженерных кейсов про работу AI-агентов в продуктовой разработке. Каждый кейс разобран не на словах, а на стенде: репро → анализ → решение → верификация → отчёт. Цифры в отчётах получены прогонами из этого репозитория и воспроизводятся одной командой; ответы моделей кешируются на диске, поэтому повторный прогон даёт те же числа без сетевых вызовов.
