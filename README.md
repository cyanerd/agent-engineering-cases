# Agent Engineering Cases

Семь инженерных кейсов про работу AI-агентов в продуктовой разработке. Каждый кейс разобран не на словах, а на стенде: репро → анализ → решение → верификация → отчёт. Цифры в отчётах получены прогонами из этого репозитория и воспроизводятся одной командой; ответы моделей кешируются на диске, поэтому повторный прогон даёт те же числа без сетевых вызовов.

## Кейсы

| Кейс | Вопрос | Вывод | Ключевая цифра | Отчёт |
|---|---|---|---|---|
| A1 | Агент бронирует билеты, 5% прогонов - другая вёрстка | Лестница: схема → инварианты → независимое чтение корзины → человек только при расхождении или невозвратной покупке → сверка после оплаты | 900 прогонов (LLM-агент и хрупкий скрипт): инварианты и чтение корзины остановили все 11 неверных заказов (1 у Flash, 10 у скрипта) и ни одного из 838 верных; подтверждение по сумме - +5-6% вопросов и 0 пойманных ошибок | [REPORT](a1-booking/REPORT.md) |
| A2 | Ночной прогон: 40 сигналов в неделю, 30 - мигание | Перепрогон до 2 раз + статистика по окну; отпечатки - для разбора. При дорогом прогоне - отпечатки + статистика | 91% поломок, 2 ложных сигнала в неделю вместо 28.5, +9% прогонов (100 историй) | [REPORT](a2-watchdog/REPORT.md) |
| A3 | Локальная модель хуже платной на части задач; как маршрутизировать и доказать качество | Каскад: тип задачи + проверки ответа дешёвой (схема, согласие сэмплов) → эскалация; не-худшесть с заранее заданной маржой + теневой режим | 480 задач: каскад 98.3% против 99.2% у «всё на дорогую» при 52% дорогих вызовов и цене в 3 раза ниже; не-худшесть на 240 задачах не доказана ([−2.1; 0] п.п.) - по симуляции нужна тень ~1000 сравнений | [REPORT](a3-router/REPORT.md) |
| B1 | Кто входит по SMS, если номер в пяти компаниях | Номер = человек, доступ = членство, согласие = версия × компания | 7 сценариев через настоящий Keycloak: наивная модель ломается, исправленная проходит | [REPORT](b1-phone-orgs/REPORT.md) |
| B2 | Агент читает почту, письмо просит выгрузить клиентов | Промпт снижает, но не обнуляет; политика вне модели и разделение прав - обнуляют | 2133 прогона, 3 модели: 0 утечек в профилях с политикой или разделением прав; адаптивные атаки пробили промпт у qwen (3/10) | [REPORT](b2-mail-injection/REPORT.md) |
| C1 | Агентский PR на 900 строк, CI зелёный, авто-мерж | Зелёный CI не про семантику; защиты процесса + контрактные тесты | Переписанный слой: CI зелёный до защит, красный после; мои защиты v1 обходились тремя способами - исправлено | [REPORT](c1-agent-pr/REPORT.md) |
| C2 | Банк + AI-агент на iOS/Android/Huawei без мобильного опыта | Capacitor поверх PWA; первым - просмотр и агент на чтение | 48 мин от PWA до сборок на обеих платформах; биометрия и Keychain/Keystore проверены на обеих, защита экрана - на Android (на iOS - по API) | [REPORT](c2-mobile/REPORT.md) |

Модели и цены: [docs/models.md](docs/models.md).

## Как запустить

```bash
pnpm i
cp .env.example .env        # вписать OPENCODE_API_KEY
pnpm typecheck && pnpm test
pnpm --filter <кейс> run case
```
