# 00 Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Каркас репозитория, на котором строятся все 7 кейсов: pnpm-workspace на TypeScript, общий клиент моделей с дисковым кешем и учётом стоимости, локальная модель, CI с проверкой секретов, приватный репозиторий на GitHub.

**Architecture:** Монорепо pnpm. `packages/llm` - единственная точка вызова моделей (OpenAI-совместимый Chat Completions для OpenCode Go и Ollama): кеш ответов на диске по хешу запроса, учёт токенов и $ по ценам из `/v1/models`. Кейсы - отдельные пакеты `a1-booking/` … `c2-mobile/` (создаются их собственными планами).

**Tech Stack:** Node 24, pnpm 9, TypeScript 5 (strict, ESM), vitest, tsx, Ollama, GitHub Actions, gitleaks.

**Spec:** `docs/superpowers/specs/2026-11-21-cases-design.md`

## Порядок планов

Этот план - первый. Планы кейсов пишутся непосредственно перед каждым кейсом, в порядке: B2 → A3 → B1 → C1 → A2 → A1 → C2 → итоговый ответ (docx). Порядок: сначала кейсы ближе всего к продукту заказчика и дешевле по инфраструктуре; выводы B2/A3 о поведении моделей используются в A1.

## Global Constraints

- Ключи только в `.env` (в `.gitignore`); в git - `.env.example` с пустыми значениями. История не переписывается, поэтому секрет не должен попасть ни в один коммит.
- Ни кода, ни названий текущего работодателя и его заказчиков в репозитории.
- README/REPORT - на русском; код и комментарии - на английском.
- OpenCode Go: base URL `https://opencode.ai/inference/go/openai/v1`, список моделей и цены `https://opencode.ai/inference/go/v1/models`, заголовок `x-opencode-session` (стабильный UUID на прогон) обязателен, иначе `400 MissingSessionID`.
- Цены OpenCode Go удваиваются по будням в UTC 01:00-04:00 и 06:00-10:00 (`multipliers` в `/v1/models`) - большие прогоны в эти окна не запускать.
- На стенды - не больше ~1/3 недельного окна подписки OpenCode Go; прочие платные API - не больше $10 суммарно.
- Повторный запуск с прогретым кешем не делает сетевых вызовов и даёт те же числа.

## Review Focus

- Изменился любой параметр запроса (temperature, tools, seed, номер сэмпла) → другой ключ кеша; одинаковый запрос → тот же ключ независимо от порядка ключей в объекте и от значения `x-opencode-session`.
- Ответ с ошибкой (4xx/5xx, `MissingSessionID`, таймаут) не попадает в кеш.
- Модель без цены (Ollama) → стоимость 0, а не NaN/исключение.
- Параллельные вызовы с одним ключом не портят файл кеша (запись через временный файл + rename).
- Ключ API не попадает ни в кеш, ни в логи, ни в `results/`.

### Task 2: `packages/llm` - клиент, кеш, стоимость

**Files:**
- Create: `packages/llm/package.json` (`@aec/llm`), `packages/llm/tsconfig.json`, `packages/llm/src/index.ts`, `src/types.ts`, `src/cache.ts`, `src/pricing.ts`, `src/client.ts`
- Test: `packages/llm/test/cache.test.ts`, `test/client.test.ts`, `test/pricing.test.ts`

**Interfaces:**
- Produces:
  - `type Provider = 'opencode' | 'ollama'`
  - `type ChatMessage` - OpenAI Chat Completions message (system/user/assistant/tool, `tool_calls`, `tool_call_id`)
  - `type ToolDef` - OpenAI `{ type: 'function', function: { name, description, parameters } }`
  - `interface ChatRequest { provider: Provider; model: string; messages: ChatMessage[]; tools?: ToolDef[]; temperature?: number; maxTokens?: number; responseFormat?: { type: 'json_object' } | { type: 'json_schema'; json_schema: unknown }; sample?: number }` - `sample` входит в ключ кеша и позволяет получить N независимых сэмплов одного запроса.
  - `interface ChatResult { message: ChatMessage; usage: { inputTokens: number; cachedInputTokens: number; outputTokens: number }; costUsd: number; latencyMs: number; cached: boolean; model: string }`
  - `function createLlm(opts?: { cacheDir?: string; sessionId?: string; fetchImpl?: typeof fetch; now?: () => Date }): { chat(req: ChatRequest): Promise<ChatResult>; totals(): { calls: number; cachedCalls: number; costUsd: number } }`
  - `function cacheKey(req: ChatRequest): string` - sha256 от канонического JSON (ключи отсортированы) запроса без `provider`-специфичных заголовков.
  - `function costUsd(model: string, usage: ChatResult['usage'], at: Date, prices: PriceTable): number`
  - `type PriceTable = Record<string, { input: number; cachedInput: number; output: number; peak?: { weekdaysUtc: string[]; hoursUtc: [string, string][]; factor: number } }>` (USD за 1M токенов)
  - `function loadPrices(fetchImpl?: typeof fetch): Promise<PriceTable>` - из `https://opencode.ai/inference/go/v1/models`, кешируется в `packages/llm/prices.snapshot.json` (коммитится, с датой) для офлайн-повторяемости.
  - `latencyMs` у кешированного ответа - исходная задержка из кеша (нужна для метрик времени в A1).

- [ ] **Step 1: Тесты кеша** (`cache.test.ts`):
  - `cacheKey` одинаков для объектов с разным порядком ключей;
  - `cacheKey` различается при разных `temperature`, `sample`, `tools`;
  - запись/чтение через временную директорию возвращает тот же `ChatResult` с `cached: true`;
  - две параллельные записи одного ключа оставляют валидный JSON.
- [ ] **Step 2: Тесты клиента** (`client.test.ts`, `fetchImpl` - заглушка):
  - для `opencode` уходит `POST https://opencode.ai/inference/go/openai/v1/chat/completions` с `Authorization: Bearer <OPENCODE_API_KEY>` и заголовком `x-opencode-session` = переданный `sessionId`;
  - для `ollama` - `POST ${OLLAMA_BASE_URL}/chat/completions` без `Authorization`;
  - второй одинаковый вызов не дергает `fetchImpl` и возвращает `cached: true`;
  - ответ 400/500 бросает ошибку и **не** пишется в кеш;
  - `tool_calls` из ответа сохраняются в `message`;
  - строка ключа не встречается в файле кеша.
- [ ] **Step 3: Тесты стоимости** (`pricing.test.ts`): `deepseek-v4.1-flash` с input 1M / output 1M вне пика = 0.15 + 0.6 = 0.75; то же в среду 07:00 UTC = 1.5; cached input считается по `cache.read`; неизвестная модель (ollama) = 0.
- [ ] **Step 4:** Запустить `pnpm --filter @aec/llm test` - падают.
- [ ] **Step 5:** Реализовать `cache.ts`, `pricing.ts`, `client.ts`, `index.ts` по интерфейсам выше. Ретраи: 3 попытки с экспоненциальной паузой на 429/5xx/сетевые ошибки. `usage.prompt_tokens_details.cached_tokens` → `cachedInputTokens`, если есть.
