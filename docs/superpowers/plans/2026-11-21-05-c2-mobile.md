# 05 C2 Мобильное приложение без опыта - Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Спайк, который отвечает на вопрос «можно ли из существующей PWA за короткий срок получить банковское приложение под iOS, Android и Huawei»: реальные сборки, проверка критичных для банкинга нативных возможностей, замер времени, таблица «что заработало / во что упёрлось».

**Architecture:** `c2-mobile/` - маленькая PWA (Vite + React + TS: экран баланса и операций на моках, чат с агентом на моках, manifest + service worker) → Capacitor 7 → нативные проекты `android/` и `ios/`. Плагины: биометрия, защищённое хранилище (Keychain/Keystore), защита экрана (FLAG_SECURE / скрытие в app switcher). Сборки: Android debug APK → эмулятор, скриншот; iOS → симулятор, скриншот. Huawei: проверка, что APK не тянет Google Play Services, описание HMS Push Kit. Журнал времени - `c2-mobile/TIMELOG.md` с отметками начала и конца каждого шага.

**Tech Stack:** Vite, React 19, TypeScript, Capacitor 7, Android SDK + эмулятор, Xcode 27.1 + iOS Simulator, Java 21.

**Spec:** `docs/superpowers/specs/2026-11-21-cases-design.md`, раздел «C2. Мобильное приложение без опыта».

## Global Constraints

- Это спайк: тесты минимальные (сборка и запуск - и есть проверка), код не продакшн. В отчёте так и написано.
- Плагины - только из открытых источников с указанием версии и лицензии; ничего не подписывать сертификатами Кирилла, сборки debug/симулятор.
- Время мерить честно: «от `npm create vite` до скриншота на эмуляторе», включая ошибки и их разбор; если шаг упёрся - фиксировать во что и сколько ушло.
- Диск: перед сборками проверить свободное место (нужно ~15 ГБ: образ эмулятора, Gradle, DerivedData); Docker и стенды B1 к этому моменту остановить.
- Ветка `case/c2`, PR, ревью подагентом.

## Review Focus

- «Запускается на эмуляторе» подтверждено скриншотом из самого эмулятора/симулятора, а не из браузера.
- Каждая нативная возможность проверена вызовом на устройстве (лог или скриншот результата), а не наличием плагина в `package.json`.
- Утверждение про Huawei основано на проверке APK (`apkanalyzer`/`aapt dump` на зависимости `com.google.android.gms`), а не на допущении.
- Таблица «что не успеем» опирается на найденное в спайке или на требования сторов со ссылкой, а не на общие слова.

### Task 1: PWA

- [ ] Vite + React + TS в `c2-mobile/`: экран «Счёт» (баланс, 10 операций из мока), экран «Помощник» (чат, ответы из мока, только чтение - «покажи траты за неделю»), manifest, service worker (offline-оболочка). `pnpm --filter c2-mobile build` проходит, `vitest` на функцию форматирования денег и на ответчик-мок. Отметка времени в TIMELOG. Commit.

### Task 2: Capacitor + Android

- [ ] `@capacitor/core`, `@capacitor/cli`, `@capacitor/android`; `npx cap add android`; сборка `./gradlew assembleDebug`; эмулятор (существующий AVD или `sdkmanager` + `avdmanager` с образом API 35 arm64), установка APK, скриншот `adb exec-out screencap`. Отметки времени. Commit (без `android/app/build`).

### Task 3: iOS

- [ ] `@capacitor/ios`, `npx cap add ios`, сборка под симулятор `xcodebuild -scheme App -sdk iphonesimulator -destination ...`, установка `xcrun simctl install`, запуск, скриншот `xcrun simctl io booted screenshot`. Отметки времени. Commit.

### Task 4: Нативные возможности для банкинга

- [ ] Биометрия (`@aparajita/capacitor-biometric-auth` или аналог): вызов на эмуляторе с зарегистрированным отпечатком (`adb -e emu finger touch 1`) и на симуляторе (Face ID enrolled, `simctl` matching) - скриншот/лог результата.
- [ ] Защищённое хранилище (`capacitor-secure-storage-plugin` или аналог): запись и чтение токена, проверка, что значение не лежит в `localStorage`/`SharedPreferences` открытым текстом (`adb shell run-as ... cat`).
- [ ] Защита экрана: Android - `FLAG_SECURE` (плагин или 3 строки в `MainActivity`), проверка: скриншот через `adb` - чёрный; iOS - скрытие содержимого в app switcher.
- [ ] Каждая проверка - строка в таблице с результатом и временем.

### Task 5: Huawei и отчёт

- [ ] `apkanalyzer dex packages` / `aapt dump badging` на собранном APK: есть ли зависимости `com.google.android.gms`/Firebase; описание HMS Push Kit (что нужно: аккаунт AppGallery Connect, `agconnect-services.json`, HMS Core на устройстве) - без сборки под AppGallery.
- [ ] `REPORT.md`: технология (Capacitor поверх PWA - почему, и альтернативы React Native / Flutter / нативка с причинами отказа), что отдать первым (просмотр + агент только на чтение), чего не успеть и почему (платежи, push под Huawei, сертификация и требования сторов к финансовым приложениям), таблица времени из TIMELOG, скриншоты. README, строка в индексе.
- [ ] typecheck/test/gitleaks, PR, ревью подагентом, merge.
