## Описание

Стенд Keycloak 26.8.2 + Postgres + API для кейса B1: кто входит по SMS-коду, если номер есть в пяти юрлицах.

- `keycloak-sms/` - собственное расширение Keycloak: выдача одноразового SMS-кода (TTL, лимиты на номер, без раскрытия существования номера) и аутентификатор direct grant по номеру и коду. Режим `naive`/`fixed` задаётся атрибутом realm.
- `db/001_app.sql` - модель приложения: человек, компании, членства со статусом, `revoked_before`, документы → версии → принятия (человек × версия × компания).
- `src/api.ts` - API в двух вариантах поверх одной базы.
- `tests/stand/` - 18 тестов против поднятого стека, из них 6 сценариев: на наивной модели ломаются, на исправленной проходят. Результаты - `results/scenarios.json`.
- CI: job `b1-stand` собирает расширение, поднимает compose и гоняет сценарии.
