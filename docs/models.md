# Модели проекта

Зафиксированы 21.11.2026 пробой `pnpm --filter @aec/llm run probe` (простой ответ, один вызов инструмента, JSON-ответ; temperature 0). Цены - из `https://opencode.ai/inference/go/v1/models`, снимок в `packages/llm/prices.snapshot.json`.

| Роль | Модель | Где | Цена за 1M in / cached in / out | Tool calling | JSON | Задержка пробы (простой / tool / json) |
|---|---|---|---|---|---|---|
| Локальная дешёвая | `qwen3:8b` (Q4_K_M, 5.2 ГБ) | Ollama на Mac, 48 ГБ RAM | $0 | да | да | 5.6 / 2.7 / 3.2 с |
| Облачная дешёвая | `deepseek-v4.1-flash` | OpenCode Go | $0.15 / $0.003 / $0.60 | да | да | 1.3 / 1.7 / 1.5 с |
| Облачная дорогая | `deepseek-v4-pro` | OpenCode Go | $0.66 / $0.022 / $1.98 | да | да | 2.5 / 2.4 / 2.9 с |

- По будням в UTC 01:00-04:00 и 06:00-10:00 цены OpenCode Go удваиваются; большие прогоны в эти окна не запускаются.
- `deepseek-v4-pro` доступна по подписке OpenCode Go, замена не понадобилась.
- `qwen3:8b` по умолчанию «думает» (`<think>`), поэтому на коротких ответах тратит 120-150 токенов вывода; на это рассчитаны времена прогонов.
- Лимит частоты OpenCode Go: при 6 параллельных запросах приходит `429` с `Retry-After: 5`; клиент ждёт `Retry-After` и повторяет до 8 раз, стенды держат 2 параллельных запроса.
